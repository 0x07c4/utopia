# 2026-10-23 — Noctalia 插件运行时验证经验

范围：`arch-laptop`，Noctalia 5.3.0，`work/desktop-interaction` 分支的
`utopia/shortcuts`。本文记录故障、证据及验证方法；2026-10-24 用户已确认通过
`Super+/` 打开后，搜索、分类切换与关闭均正常。

## 两个故障不能混为一谈

新增启动器 provider 后，插件 lint、配置验证和重载请求均成功，插件清单也显示
已启用，但用户搜索“快捷键”没有结果。日志显示新 manifest 已被识别；仅对帮助
插件禁用再启用后，才出现新增脚本的文件监听，实际查询也开始产生结果。
这支持“清单发现不等于运行入口已注册”的诊断，但没有在最小独立插件或最新
上游版本上复现，尚不能断言上游具体哪一段代码存在缺陷。

之后用户能进入帮助面板，但搜索、分类和关闭均失效。插件日志明确报告
`onSearchChange` 连续超过 CPU 预算，随后报告面板因重复超时被禁用。
因此三个控件同时失效属于运行时被停止后的连带表现，不能逐个当成按钮绑定错误。

Noctalia 5.3.0 的普通脚本调用预算为 25 ms；重复超时会停止向不健康的运行时
发送事件。依据是固定上游版本的
[script_runtime.cpp](https://github.com/noctalia-dev/noctalia/blob/a33122c4208a385e19c9a252e65e2751b2c44fbb/src/scripting/script_runtime.cpp)。

## Utopia 的修复

原实现每次输入都重新组合搜索文本、翻译名称并构建整张列表的行与键帽。
现改为在同一配置/语言周期内复用翻译、搜索索引、键帽以及普通/选中行视图；
刷新时全部清空。缓存行的点击回调根据当前过滤结果查位置，避免沿用旧行号。
不提高宿主预算，不减少实际收录的键位，不禁用搜索或分类。

未逐项隔离这些重复工作的成本，不能声称某一个函数是唯一瓶颈。
目前证据是原实现出现真实超时，而缓存后的完整回调在同一机器上通过连续检查。

## 验证应该覆盖的层次

1. **静态层**：读取器测试、两套配置解析、插件 lint、配置验证及差异检查。
   这些不能证明事件运行正常；当时通过的 200 项测试没有覆盖实际 Luau 交互链路。
2. **注册层**：新 entry 必须真正注册。不能以清单已启用或 `panel-open` 返回成功
   代替查询验证。新增 entry 后重新启用受影响插件，并等待后台启用完成。
3. **回调层**：用临时 IPC 诊断调用真实搜索、分类、导航和关闭处理函数，检查
   返回结果、日志以及关闭后的面板状态；不只检查“没有报错”。诊断不输出私人
   数据，完成后移除，并确认现场源码与仓库一致。
4. **用户交互层**：真实输入、点击分类、点击关闭，以及从启动器进入后的行为。
   直接调用处理函数绕过了控件事件路由，不能代替这一层的验收。

本次先验证“快捷键”“帮助”和 `shortcuts` 实际产生启动器结果，再对优化后的
面板连续执行 29 次宽泛/清空/无结果搜索、分类切换、键盘移动及关闭回调。
全部完成，无新的错误或超时；非关闭回调计时约 0.5–5.3 ms，状态确认关闭成功。
这是当前机器上的诊断计时，不是跨机器性能承诺，也不能排除冷启动或更大配置
带来的开销。正式代码已恢复；2026-10-24 用户已确认最后一轮真实输入、分类和关闭
正常，结束这次面板超时故障的用户验收。

## 后续维护与上游边界

- 对此类完整列表 UI，性能回归要包含宽泛搜索、清空恢复整表、反复分类切换，
  不能只测返回很少结果的精准关键词。
- 面板整体失去响应时，先查插件专属错误与宿主禁用记录；保留可关闭性并避免
  反复重启整个桌面来掩盖问题。恢复时只重载受影响插件，配置替换前保留备份。
- 将验证结果分别写成“静态通过”“实际回调通过”“用户确认”，不要提前宣称
  产品交互已正常。本次让用户遇到两个静态验证未覆盖的问题，属于验证范围不足。
- CPU 超时首先由 Utopia 自身消除冗余工作，目前没有证据说明宿主预算或保护机制
  有缺陷，不为此向上游提交放宽预算的补丁。
- 新增 provider 的重载行为可作为上游候选问题：用最小插件复现“先启用单一面板，
  再新增 provider，重载后查询，禁用再启用作对照”，核对最新版本及已有报告，
  明确预期重载语义之后，再决定提出 issue 或附回归测试的修复 PR。
  尚未向上游发布 issue 或 PR。

后续已用独立最小插件在隔离会话中复现入口重载问题，并核对当前上游源码；
步骤、正反对照和验证限制见[上游报告草稿](2026-10-23-noctalia-manifest-reload-report.md)。
