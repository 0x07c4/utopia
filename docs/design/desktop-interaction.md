# 桌面操作入口与帮助体验

更新：2026-10-23。所属分支：`work/desktop-interaction`。

本文定义本分支的完整交付范围，不是快捷键面板的功能说明，也不表示所有设计
已经实现或部署。当前运行事实与跨机器暂停点见 [handoff](../handoff.md)，
插件技术限制与恢复步骤见 [插件说明](../../desktop/noctalia/plugins/utopia-shortcuts/README.md)。

## 目标与分支边界

交付一套**一致、可发现的桌面操作入口**。帮助面板是用户理解这套交互的入口，
不是以一个面板代替整套交互设计。用户应能记住少量规律，并通过帮助找到其余操作。

本分支统一处理四部分：

1. 操作入口：应用、窗口、工作区、桌面面板、媒体和会话的主入口、备用入口，
   以及重复、缺失、语义不一致的绑定。
2. 帮助体验：真实配置驱动、准确中文、合理分类、备用组合、搜索与滚动。
3. 桌面一致性：快捷键、帮助、顶栏和控制中心对同一功能采用一致名称和行为。
4. 验证与交接：两套主机配置的静态验证、当前笔记本的实际验收、备份和恢复。

不包含主题重做、游戏适配、通话测试、屏幕共享/录屏实现、系统服务改造，
也不引入通用部署框架。笔记本没有当前游戏需求；台式机专属规则与实验不得被
共享文件覆盖。发现范围外问题时记录边界，不顺手扩展。

在同一分支完成这套交互，最终统一一个 PR。可以按入口策略、帮助实现、回归验证
组织清晰提交，不按每个测试、文档补记或小调整另开分支/PR。
提交与推送需要当前任务授权，不能因为一项局部测试通过就提前结束整轮工作。

## 操作语言

原则是强化已有规律，不为了看起来统一而制造大量肌肉记忆迁移：

- `Super + 字母` 优先用于常用应用/功能，例如已确认的 `T` 终端、现有 `B` 浏览器。
- 方向键和 `H/J/K/L` 是两种习惯的并存入口，不因去重显示而隐藏其存在。
- 在已有映射允许的范围内，聚焦方向与移动方向保持对应；修饰键的含义应可解释。
- “关闭窗口”“锁屏”“退出桌面会话”“关闭显示器”必须明确区分，不能笼统称为关闭。
- 标题描述用户目标，而不是 `controlCenter`、`sessionMenu` 或 shell 命令。
- 重复组合不自动等于多余：确认是否有不同的键盘习惯/设备需求，再决定保留或移除。

**增删或重分配键位先向用户确认。** 不因为某个组合暂时未占用就为通知或剪贴板
随意分配；先放进完整映射中检查冲突与含义。文字、搜索和展示改进不得暗中改变动作。

已明确确认的键位决策：

| 功能 | 决策 | 边界 |
| --- | --- | --- |
| 快捷键帮助 | 保留 `Super + /` | 使用同键上的问号形成帮助联想；不照搬 Omarchy 的 `Super + K` |
| 原生帮助 | 删除 `Super + Shift + Esc` | 用户明确不需要第二个原生回退入口，也不显示回退提示 |
| 终端 | 主入口为 `Super + T`，删除 `Super + Enter` | 用户认为 T 更容易关联终端；其他含 Enter 的组合不因此改变 |
| 应用启动器 | 现有 `Super + D` 和 `Super + Ctrl + Enter` 均保留 | 新面板应显示备用组合；是否精简尚未决定 |
| 通知中心 | 新增 `Super + N` | 直接打开控制中心通知页，不读取或清空通知 |
| 剪贴板历史 | 新增 `Super + Y` | 打开已有历史面板，不覆盖 `Super + V` 的浮动动作 |
| 播放/暂停键 | `XF86AudioPlay` 使用 `media toggle` | 用户已确认改为播放/暂停切换 |
| 独立暂停键 | `XF86AudioPause` 使用 `media pause` | 用户已确认替换原来的 stop，其他媒体键不变 |

## 帮助面板的目标体验

### 信息结构

- 常用操作靠前；完整有效映射仍然可查。具体排序应基于实际操作清单，不复制
  其他项目的应用列表。
- 按应用、窗口与布局、工作区、桌面、媒体与亮度、截图、会话等用户任务分类。
  “其他”不能成为大量未知操作的永久归宿。
- 所有有效备用组合可见。同一动作可以紧凑展示多个组合，但不同动作不能因名称
  相似被错误合并。
- 工作区数字序列等规律性绑定可考虑压缩为范围展示。必须从真实条目推导，不能
  写死假定 1–9 都存在；具体组合仍须能查到。
- 中文说明简洁、准确。搜索应逐步支持常见说法，例如“文件夹”能找到文件管理器。
  搜索同义词属于说明层，不改变键位或执行语义。

### 布局与操作

搜索栏、分类筛选、说明与键帽对齐的列表为第一版基础，优先可读性和紧凑度，
不要求额外的装饰性卡片。长键位或多个备用组合不能挤掉说明、撑出屏幕。

面板高度受可用屏幕空间约束，结果内部滚动，搜索与关闭入口保持可见。
鼠标滚轮和键盘导航都应可用；浏览或搜索不能执行条目。面板无需依赖分页来补救
超高长表，必要的按页导航只是滚动操作的一种方式。

鼠标入口复用现有顶栏应用启动器：搜索“快捷键”“帮助”或 `shortcuts`，
选择本地化的“快捷键说明”，打开同一个只读面板，副标题提示 `Super+/`。
帮助插件提供全局搜索结果及 `/keys` 专属入口，不新增桌面文件或顶栏图标，
也不替换控制中心的默认功能块。此前控制中心入口提案由此收敛。

此选择基于对当前 Noctalia 5.3.0 的核对：顶栏已存在 launcher；上游自带的
Panels provider 会列出插件面板，但默认不参与全局搜索，插件面板名称直接来自
英文 manifest 名称，不能满足直接搜索中文帮助的需要。专用 provider 只补这一项
发现性，不修改整个 Panels provider 的搜索策略。启动器新版布局来自上游更新，
本分支没有调整其布局。

### 一个事实来源

键位、动作和备用组合来自当前实际配置及其引用，不能另维护一份容易过期的
键位清单。中文名称、分类、同义词和排序可以有薄的说明层，但不能取代真实配置。

必须区分“磁盘上的配置”和“合成器已加载的配置”。目前的读取程序不是通用 KDL
解析器；遇到不支持的语法、越界引用或无效映射时，明确报错，不把部分结果称为完整。
未知自定义动作应明确标识、列入审查，不能猜测功能或展示敏感 shell 参数。
不读取聊天、剪贴板、通知内容或账号状态来生成帮助。

  插件 lint、Noctalia 配置验证通过。台式机未部署。
- 已实现并备份部署启动器帮助搜索入口，插件已启用并重载；已发出 `/keys`

  已通过临时诊断确认“快捷键”“帮助”和 `shortcuts` 都实际返回帮助结果且无报错；
  诊断已撤除。用户已确认点击可以进入面板，但随后搜索、分类、关闭均失效。
  日志确认连续搜索回调 CPU 超时使宿主禁用面板；现已缓存本轮配置的翻译、搜索文本、
  键帽和行视图，刷新时清空，点击按过滤后的当前位置解析。优化版已备份部署，
  29 次连续真实回调检查无超时，测得低于 5.3 ms（宿主预算 25 ms），关闭状态已确认。
  临时探针已撤除；2026-10-24 用户已确认修复后的输入、分类与关闭恢复正常。

- **交付边界**：核心帮助入口与交互已通过用户验收；实体媒体键与不同播放器、
  多屏和锁屏时媒体行为仍未现场验证。会话退出、锁屏、截图和播放不为代理验证而触发。
  后续上游评审与合并独立跟进，不阻塞使用已部署的帮助插件。

初审发现 `XF86AudioPause` 映射为 `media stop`。在核对命令接口、取得用户确认后，

## 下一步顺序与验收

首轮完整入口审查已记录在
[操作对照表](desktop-interaction-inventory.md)，初审覆盖 133 个共享绑定，获批新增
入口后更新为 135 个绑定，并保留没有键位的
已声明面板入口。它是审查快照，不是另一份运行时键位清单；问题和建议不等于已获准修改。

1. **先出完整操作对照表**：操作、当前键位/鼠标入口、实际动作、显示名称、
   分类、重复/缺失/风险、建议、用户确认状态。覆盖现有配置，而非只列容易修的几项。
2. 据表提出一轮入口策略。保留已明确决定的键位，集中确认其余增删与重分配，
   不要求用户逐行批准无行为变化的文案修正。
3. 在同一分支统一改善命名、分类、搜索、别名和界面，以及确认后的入口改动。
4. 在隔离环境验证两套主机配置与相关测试。部署前检查现场差异、时间戳备份，
   仅应用已审查文件，不影响台式机游戏专属适配。
5. 笔记本实际验收：最终快捷键、鼠标入口、中文/按键/同义词搜索、分类、长组合、
   备用键位、鼠标与键盘滚动、关闭/重开、错误提示；核对代表性动作的实际含义。
   退出、关机、锁屏等不为验收而由代理擅自触发。
6. 记录明确证据与未验证边界，再整体整理提交和 PR。测试、lint 或成功打开面板，
   均不单独构成整个 `desktop-interaction` 分支完成的依据。

完成标准是：本轮对照表中约定处理的问题已解决或经用户明确延后，实际入口与
帮助一致，代表性操作验收通过，恢复路径清楚，无未解释的现场覆盖。未选入本轮的
大型交互改造保留为后续任务，不靠无限扩大范围来维持分支。
