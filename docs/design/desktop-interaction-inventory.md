# 桌面操作入口对照审查

审查日期：2026-10-23，2026-10-24 完成内容复核与帮助交互验收。分支：`work/desktop-interaction`。
所属设计：[桌面操作入口与帮助体验](desktop-interaction.md)。

这是当前共享配置的**审查快照**，不作为运行时帮助的第二份数据源。
当前事实来自 `desktop/niri/cfg/keybinds.kdl`、`.config/noctalia/bar.toml`、
插件读取器和本机 Niri 26.04 / Noctalia 5.3.0 的只读命令帮助。
审查没有触发退出、关机、锁屏、截图、麦克风或媒体控制，没有查看剪贴板或通知内容。

以下在组合的修饰位置，`S` 表示 Super，`C` 表示 Ctrl，`A` 表示 Alt，
`⇧` 表示 Shift；末位单字母是字面按键，例如 `S+S` 是 Super+字母 S。
`←/→`、`上/下` 等按对应顺序配对；范围只为压缩这份审查快照，不表示面板已实现
范围折叠。方向键与 H/J/K/L 是备用组合，不是两套不同动作。
“顶栏入口”仅表示配置声明了对应 widget；其默认点击/滚轮手势仍由 Noctalia
提供，不能仅凭 widget 存在就宣称所有现场手势已经验收。
